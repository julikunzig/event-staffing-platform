🎯 PRÓXIMOS PASOS (30 MINUTOS)
═══════════════════════════════════════════════════════════════════════════

PASO 1: CREAR TOKEN GITHUB (2 min)
   https://github.com/settings/tokens
   → Generate new token (classic)
   → Scopes: repo, workflow
   → Copiar token

PASO 2: PUSH A GITHUB (2 min)
   git config --global credential.helper osxkeychain
   git push -u origin main
   Username: julikunzig
   Password: <pega el token>

PASO 3: CREAR RAMAS (2 min)
   git checkout -b develop && git push -u origin develop
   git checkout -b staging && git push -u origin staging
   git checkout main

PASO 4: CONFIGURAR GITHUB (5 min)
   • Proteger rama main
   • Agregar 3 secrets
   • Habilitar GitHub Actions
   Ver: CONFIGURAR_GITHUB_RENDER.md

PASO 5: CONFIGURAR RENDER (10 min)
   https://render.com
   → Sign up with GitHub
   → Create Blueprint
   → Connect repository
   → Deploy
   Ver: CONFIGURAR_GITHUB_RENDER.md

PASO 6: ESPERAR DEPLOYMENT (5-10 min)
   Render desplegará automáticamente
   Frontend: https://event-staffing-frontend.onrender.com
   Backend: https://event-staffing-backend.onrender.com
